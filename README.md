Welcome to **BTD SMP**, a heavily customized modded Minecraft survival experience built from the ground up.

This server is not just a collection of mods — it is a constantly evolving project with custom content, balancing, scripting, and infrastructure managed through a real Linux server environment.

---

# ✨ About The Server

BTD SMP is a custom modded Minecraft server designed around:

- ⚔️ Enhanced combat
- 🏰 Exploration and adventure
- 🌎 Expanded world generation
- 🧙 Custom gameplay mechanics
- 🔥 Bosses and challenging encounters
- 🛠️ Custom server-side improvements
- 📈 Continuous updates and balancing

The server is hosted on an **AWS EC2 Ubuntu Linux virtual machine**, providing a dedicated always-online environment.

---

# ☁️ Server Infrastructure

The server runs on:

- **Cloud Provider:** AWS EC2
- **Operating System:** Ubuntu Linux
- **Server Management:** SSH
- **Backup System:** Manual + versioned backups
- **Deployment:** Git-based version control

The server is maintained like a real software project, with updates tracked through GitHub.

# 🔄 Updating The Server

Updates are managed through Git.

Example:

```bash
git pull
```

Future updates follow the version system:

```
v1.0.3
      ↓
v1.0.4
      ↓
v1.0.5
```

Each update contains improvements, fixes, and new content.

---

# 💾 Backups

Server backups are handled separately from the Git repository.

Excluded:

- World saves
- Logs
- Runtime files
- Generated files

This keeps the repository clean while ensuring important server data can still be safely backed up.
